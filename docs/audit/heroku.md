## Findings
- heroku-09 (line 28): doc shows `issued: wft_a1b2c3d4e5f6...`; the CLI prints `Token created: <token>` (cmd/weft/main.go:1103, plus `Label:`/`Env:` lines). Doc stale. Replace with `Token created: wft_a1b2c3d4e5f6...` / `Label: heroku` / `Env:   prod (stamped on every row from this token)`.
- heroku-19/20/21/42 (lines 50-57, 100): examples use 3-segment `/log/myco/myapp/...` while step 1 mints with `--env prod`; real layout is `/log/<ns>/<env>/<svc>/<kind>` (`ls /log/acme/api` fails, `/log/acme/prod/api` works). Doc ambiguous/stale. Suggest `ls /log/myco/prod/myapp` and the same env segment in lines 57, 70-74, 100, with a note that env-less tokens give the 3-segment form.
- heroku-36 (lines 79, 88): heading and prose say `/metrics` / `<appname>/metrics`; actual file is `metrics.log`. Suggest "`<appname>/metrics.log`".
- heroku-46 (line 107): "reissue it from Tokens": CLI has only create/list/revoke (no reissue). Suggest "revoke it and mint a new one (see Tokens)".
- heroku-47 (lines 108-109): trailing slash and missing prefix both return plain 404 (not a parse error). Suggest "a 404".
- heroku-06/05 (line 22): `token list` shows multi-namespace tokens (`acme,globex`), so "single namespace" may be incomplete. Check against tokens.md.
- Style: line 62 "sub-app" vs "service"; line 112 "app" vs service. Ambiguous wording only.
- Not hit: `watch`/durations/globs/`~` do not appear in this doc. Generated corpus (connect-heroku.ts, help_corpus_gen.go) static check: no stray {{ }}; `&lt;`/`&gt;` appear only as HTML entities in the generated web doc (expected); table renders as columns in the man text. Clean.
