## Findings

- **scripts-11 / scripts-12 / scripts-45** (l.25, 31-32, 103): doc uses bare `api.log`, `disk.log`; `count_errors api.log` -> `query: unknown source: api`; `cat api.log | ...` same. Working form is the 4-segment path relative to /log: `count_errors acme/prod/api/main.log` (270040). `count_errors /log/acme/...` with leading /log returns 0 (path doubles). Doc stale. Proposed: body `cat /log/$1 | grep ERROR | wc -l`, call `count_errors acme/prod/api/main.log`, and `cat /log/acme/prod/api/main.log | extract_ids | sort -u | wc -l`. - **scripts-45 / scripts-43** (l.103): a Lua /bin script used as a stage after a log read fails: `cat /log/acme/prod/api/main.log | tail -500 | severity` -> `compute exit 127: bash: severity: command not found` (same for status.lua). Same scripts work when stdin is a local printf. Likely product bug (compute worker lacks /bin scripts) or dev-stack limitation; confirm on prod. Doc itself describes this as a supported use.
- **scripts-19 / scripts-17** (l.47): `cat < file` -> `query: plan: plan: cat: missing pseudofile argument`; `wc -l < file` and `grep a < file` work. Product bug (or doc should note). "Effectively the full bash grammar" is overstated (`command -v`, `type awk` not available).
- **scripts-26 / scripts-27** (l.57): `less` listed as a builtin; in a pipe it is a plain pass-through with no paging; `less file` -> `bash: less: command not found`. Product gap; suggested doc: drop `less` from the builtin list until ModeLess lands.
- **scripts-32 / scripts-33** (l.72-75): `os.date` is available (doc lists only clock/time/difftime); `loadstring` is still available although doc says load family disabled. Doc stale or sandbox leak; the product-side question is whether `loadstring` should be removed.
- **scripts-51 / scripts-49** (l.115): `git log /bin/t1`, `git show /bin/x`, `git diff /bin/x` -> `fatal: bad revision`; needs `git log -- /bin/x`. Doc should give the `--` form (or link to git).
- **scripts-29 / scripts-42**: `weft.avg` on an unknown cron returns `nil` plus message `watch "nonexistent": record not found`; internal error text still says "watch" (user-facing term is cron), and `%.2f` on nil would crash the doc's example. Product wording; maybe doc should show a nil guard.
- **scripts-34**: 30s timeout not verifiable (CLI client times out at 10s).
- **scripts-52**: ambiguous "five most recent past versions" (5 or 5 plus current?); needs a human with 8 saves.
- **scripts-35**: `arg` verified only as empty table inline; positional arg binding for Lua needs a saved script (🔒).
- **scripts-10/-08**: seeded count_errors uses `awk 'LEVEL == "ERROR"'` rather than grep, fine, but doc example differs from the product's own seeded script.
